# Mobile app (Flutter)

Teodora's part of Lab 7: the first functional version of the app, for Android (and web).

| Screen | What it does | Backend |
|---|---|---|
| Login / Create account | patient, doctor or student account; the JWT is saved, so the user stays logged in | `POST /api/auth/register`, `POST /api/auth/login`, `GET /api/auth/me` (Federica) |
| Analyze | X-ray from the camera, the gallery or a PDF / DICOM file, body part, "Analyze" | `POST /api/analyses` (Alexandra's contract) or the demo analysis |
| Result | the X-ray with a box and the confidence for each fracture, heatmap on / off, summary; a warning for patients and students; "Compare all models" for verified doctors; "Ask a doctor for an appointment" for patients | `GET /api/analyses/{id}/comparison` |
| History | past analyses, opened again with their result | `GET /api/analyses/history` |
| Appointments | the patient asks a doctor (by the doctor's ID), the doctor confirms or sends a reminder, both can cancel | `/api/appointments` (Federica, State pattern) |
| Notifications | appointment confirmed / cancelled / reminder, mark as read | `/api/notifications` (Federica, NotificationAspect) |

## Run it

The `android/` and `web/` folders are generated by Flutter the first time:

```
cd mobile
flutter create --project-name bone_fracture_app --org com.bonefracture --platforms=android,web .
flutter pub get
flutter analyze
flutter test
```

`flutter create .` does not overwrite the files that already exist (`lib/`, `test/`, `pubspec.yaml`).

The backend runs on HTTP during development, so Android must allow it. In
`android/app/src/main/AndroidManifest.xml` add the internet permission and `usesCleartextTraffic`:

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <uses-permission android:name="android.permission.INTERNET"/>
    <application
        android:usesCleartextTraffic="true"
        ...
```

Start the backend (`mvn spring-boot:run` in the project root), then the app:

```
flutter run                                                       # Android emulator: the backend is 10.0.2.2:8080
flutter run --dart-define=API_BASE_URL=http://192.168.1.20:8080    # real phone on the same Wi-Fi (the computer's IP)
flutter run --dart-define=USE_MOCK_ANALYSIS=false                 # once POST /api/analyses exists on the backend
```

## Demo analysis

`POST /api/analyses` and the trained model are not ready yet, so by default the analysis runs on the phone
(`MockAnalysisService`): after about a second it returns a plausible box for JPG / PNG images, the same one for the
same image, and the app shows a "Demo analysis" banner. Everything else (accounts, appointments, notifications)
uses the real backend. With `USE_MOCK_ANALYSIS=false` the app sends the X-ray to the backend (`HttpAnalysisService`)
and shows the image returned in `imageUrl`, because the boxes are in the pixels of that image.

## Structure

```
lib/
  main.dart                 app, theme, restores the session
  app_scope.dart            the services and the logged-in user, shared by all screens
  config.dart               API_BASE_URL, USE_MOCK_ANALYSIS (--dart-define)
  models/                   User, Analysis / Detection / Comparison, Appointment, AppNotification (JSON of the API)
  services/                 ApiClient (JWT, ProblemDetail errors), AuthService, AnalysisService (Http + Mock),
                            AppointmentService, NotificationService
  screens/                  login, register, home (4 tabs), analyze, result, comparison, history, appointments, notifications
  widgets/                  XRayViewer (boxes + heatmap over the image), ImageFit, common widgets
test/                       JSON parsing, box position on the screen, start screen
```
